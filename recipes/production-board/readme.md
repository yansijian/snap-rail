# 产线看板组合

标准基座之上加装 **ModbusTCP 采集驱动、班产统计（trend）与终端作业套件
（suite-terminal-ops）**——设备管理、点位采集、班产统计、作业流程一条链，
是给开发者「看到具体实现效果」的示范组合。

## 安装

终端「设置 → 插件市场」填入插件源地址（如 `http://192.168.1.10/snap-rail/plugins/`），
在「组合 → 场景组合」区对 **产线看板** 点「一键安装」。装完后**需要重启一次**
（页面类插件随重启挂载），重启后即进入终端作业界面。

## 五分钟复现效果（演示设备手动建）

组合只保证插件就位；设备/组/点住在底座表里，演示数据按下面三步手建：

1. **建设备**：「设置 → 设备管理」→ 新建设备
   - 名称：`demo-plc`；驱动：`ModbusTCP`；地址：`127.0.0.1:1502`
   （没有真 PLC 也没关系——先建好结构，接上任何 Modbus 仿真器即可看到数据流动）。
2. **建组与点**：在 `demo-plc` 下建组 `workshop`，添加点：
   | 点名 | 类型 | 说明 |
   |------|------|------|
   | `count` | int32 | 产量计数（递增） |
   | `rate` | float32 | 实时速率 |
   | `running` | bool | 运行状态 |
3. **看效果**：
   - **终端作业页**：工号登录 → 生产流程页选择 `demo-plc` 设备开始作业；
   - **班产统计**：登录锚定班次后，`count` 点的计数按 8 小时桶累计，
     产量看板出现实时曲线与班次统计；
   - **设备管理页**：驱动连接状态、最近采样值实时刷新。

## 它演示了什么

- **驱动是纯协议适配器**：`driver-modbus` 只上交 zod schema + 连接适配，
  设备/组/点全部住在 equipment 底座表，由统一的设备管理页管理。
- **工具插件读底座不碰存储**：trend 通过计数绑定点消费底座数据，
  自己的班产表在独立命名空间。
- **套件单活**：启用产线看板的作业套件会自动停用其他互斥套件——
  一台终端一次服务一个场景。
