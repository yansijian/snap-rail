# 标准基座组合

一键装成**可用的空终端**：存储后端（store-sqlite）、设备底座（equipment）、
界面框架（framework-shadcn）与统一设置/设备管理页全部就位，并通过
`@snap-rail/equipment/rpc` 打通渲染端 wire 桥。

## 安装

终端「设置 → 插件市场」填入插件源地址（如 `http://192.168.1.10/snap-rail/plugins/`），
在「组合」区对 **标准基座** 点「一键安装」——缺失的插件会先逐个从源下载落地，
最后写入 `recipe-standard-base.yml` 组合预设并热生效。

## 它是什么

- **标准安装单位**：新终端上手的第一步，装完即是一个干净、可登录、可配置的工业终端。
- **三方插件的公共靶台**：在标准基座之上开发与验证插件，任何场景组合都以它为公共前缀。
- **可整体移除**：「移除」只删组合预设文件；已装的插件如需清理，去「插件管理」逐个卸载。
