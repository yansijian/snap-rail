# 标准基座组合

一键装成**可用的空终端**：存储后端（store-sqlite）、设备底座（equipment）、
界面框架（framework-shadcn）与统一设置/设备管理页全部就位，并通过
`@snap-rail/equipment/rpc` 打通渲染端 wire 桥。

## 安装（离线优先）

在联网 PC 下载 `standard-base.zip`（官网组合套件页或 Release 资产），拷进内网后
把 zip 拖进终端「插件」页或引导页：

- 客户端按内容识别组合形式，逐个安装缺失/需更新的成员（同名且本机版本更新时保留）；
- 全部成功后原子写入 `<home>/presets/recipe-standard-base.yml` 并热生效；
- 组合包本身不签名，每个成员 zip 保留自己的发布签名，预览逐成员显示验证结果。

若终端能访问插件源，也可以在「插件」页搜索安装各成员，效果相同。

## 它是什么

- **标准安装单位**：新终端上手的第一步，装完即是一个干净、可登录、可配置的工业终端。
- **三方插件的公共靶台**：在标准基座之上开发与验证插件，任何场景组合都以它为公共前缀。
- **可整体移除**：删除 `<home>/presets/recipe-standard-base.yml` 即停用组合；
  已装的插件如需清理，去「插件」页逐个卸载。
