# snap-rail 图标 · 概念稿

一条满幅导轨，一个卡进座里的模块。导轨是内核，模块是插件，模块周围那圈负空间是热插拔的座位。

## 语义

| 元素 | 含义 |
| --- | --- |
| 满幅钴蓝导轨 | 底座/内核：永远在场，插件装在它上面 |
| 白色模块 | 一个插件；实体、可拔插、不透明 |
| 模块四周 34 单位的负空间 | 座位：模块是"落进槽里"的，不是贴上去的 |
| 单点绿色 LED | 设备在运行（红/黄/绿在本产品里是状态语义） |

不画齿轮、电路板走线、芯片、六边形网格——工业软件的陈词滥调，而且 16px 全糊。

## 规格

- 1024 网格，全部落在 8 的倍数上；圆角：底板 228、模块 56。
- 导轨高 240（占画面 23%），左右满幅出血，被底板的圆角切掉——"这条轨还在画面外继续"。
- 模块 380 × 480，上下各伸出导轨 120；座位（moat）34。
- 颜色直接取自出厂钴蓝主题，不新增色值：

| 用途 | 值 |
| --- | --- |
| 底板 | `#171F2A` → `#0A0E13`（浅色：`#E7EDF5` → `#D1DAE7`） |
| 导轨 | `#5A76FF` → `#3A56E4`（106° 斜向，像有光照） |
| 模块 | `#FFFFFF` → `#D8E1EC`；浅色主题反过来用墨色 `#1B2430` → `#0D131A` |
| LED | `#3FB950` |

- 导轨上沿 6 单位高光、下沿 6 单位暗边：读起来是加工过的金属，而不是一条色带。
- 模块永远和底板反着来：深底白模块、浅底墨模块。同一个"实体卡在轨上"的读法，两种主题都成立。

## 小尺寸不是缩图

≤ 24px 用另一套画法重新画：导轨加粗到 300、模块放大到 460、去掉座位缝与阴影与 LED。
16px 上仍然能读出"白块卡在蓝轨上"，而不是一团灰。

## 交付

| 文件 | 用途 |
| --- | --- |
| `snap-rail-icon.svg` | 母版，1024，深色主题 |
| `snap-rail-icon-light.svg` | 浅色主题 |
| `snap-rail-icon-{1024..16}.png` | 逐尺寸渲染（不是一张图缩到底） |
| `alt-din-row-512.png` | 备选：三模一轨，故事更完整但 16px 会糊 |
| `tray-*.png` / `tray-dark-*.png` | 单色托盘图标，深墨/浅墨两版 |
| `snap-rail.ico` | 16–256 七个尺寸，每档都是对应尺寸的绘制 |
| `preview.png` | 评审用的一张图 |

## 生成

```sh
python docs/brand/icon/generate.py
```

只依赖 Pillow + numpy，不出网。改 `generate.py` 里的几何常量即可重出全套。
