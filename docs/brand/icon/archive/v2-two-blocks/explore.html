snap-rail · 图标选型

不做导轨，做接合部：一台底座，和一个能从它上面摘下来的部件。

  • 1024 网格，圆角 228
  • 缝宽固定 64（16px 上的 1px）
  • 颜色只取出厂钴蓝 token
  • 不画齿轮、电路、状态灯
背景
C1

落座

模块卡在底座角上，一半在里，一半在外

底座 624² · 模块 352² · 缝 64 · 外探 112

它说了什么
  • 一大块是底座，一小块是插件，缝就是座位。
  • 模块一半在外，读得出“可以拔走”，不是焊死的。
它没说清的
  • 角上的小块容易读成徽标 / 通知点。
  • 缝太规整时会被看成拼图缺口。
C2

嵌位

模块整个嵌进底座的角里

底座 672² · 模块 320² · 缝 64 · 外侧与底座齐平

它说了什么
  • 模块是“装进去”的，外侧和底座齐平，像抽屉归位。
  • 两块共用一个圆角语汇，看起来是同一套零件。
它没说清的
  • 齐平之后只剩下颜色差，小尺寸上可能读成一个角标。
  • 没有“拔出来”的方向感。
C3

侧插

模块从侧面插进底座

底座 560² · 模块 280² · 缝 64 · 插入 64

它说了什么
  • 模块沿一条边插进去，读得出“插槽”和“插拔方向”。
  • 底座是大面，模块是侧面凸出的小面，主次分明。
它没说清的
  • 会被读成相机手柄 / 电池仓这类“设备加附件”。
  • 左右不对称，在图标网格里会显得偏。

另外几个方向试过就淘汰了：两块并列（16px 读成暂停键）、三块同底（读成柱状图）、一个整体被缝分成两块（像两块面板）。在 16px 上，只有“小块坐在大块里”这一类剪影还站得住，所以这里只比三种落座方式。

选型请在对话里回 C1 / C2 / C3，我按选中的那一个出全套尺寸与 SVG。
