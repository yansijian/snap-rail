under your control

自由，但不失控。

插件化不等于把现场交给运气。数据在哪、谁签的、装了什么、怎么退回去， 都应该有明确答案。

01 / LOCAL

数据留在本机

每个命名空间一个 SQLite 库文件，默认在 %APPDATA%\snap-rail；不依赖云端。

02 / OFFLINE

断网也能交付

客户端与场景包都能离线拷贝安装；车间不需要访问插件服务器。

03 / SIGNED

装前先看清

插件带 Ed25519 发布签名；安装预览显示来源、版本与验证状态，组合包逐成员校验。

04 / UNIFIED

现场归一化

驱动、画面、作业流程跑在同一块终端上——少装几套软件、少几块触摸屏，生产管理和现场都更整洁。

before you install

先把丑话说在前面。

能做什么、需要什么、哪里会卡，写在下载之前，比装完才发现有用。

支持哪些 PLC / 协议？
内置 ModbusTCP 与 EtherNet/IP。更多协议通过驱动插件扩展；驱动是纯协议适配器，设备、组、点由底座统一管理。
一定要联网吗？
不。客户端与场景包都可以在联网 PC 下载后拷进内网安装；车间不需要访问插件服务器。终端内的“插件源”是可选能力，用于在线搜索和更新。
数据存在哪里？会上传吗？
默认在 %APPDATA%\snap-rail 下的本地 SQLite 库；可以用 SNAP_RAIL_HOME 改目录。当前版本不含遥测。是否接入云端由你装什么插件决定。
Windows 提示“未知发布者”怎么办？
安装包目前没有做商业代码签名，Windows SmartScreen 会提示。点“更多信息 → 仍要运行”即可。企业部署可以自行签名；插件本身另有 Ed25519 发布签名与安装预览。
能不能做 HMI / SCADA / 控制器？
同一个内核，形态由插件决定。今天默认交付终端 / HMI；SCADA 工作站、专用 HMI 面板、边缘控制器都可以由插件组合自行扩展长出来。具体实时性、现场总线和安全等级，取决于运行平台与项目定义——我们不在官网上给你画能力上限。
没有 PLC 能试吗？
可以先用 Modbus 仿真器或模拟设备把“建设备 → 测试 → 建点 → 看值”走通；真实设备仍需现场核对地址、单元号和字节序。
