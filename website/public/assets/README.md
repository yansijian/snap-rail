# 素材槽位说明

本目录存放官网的录制素材。**文件缺失时网站自动显示 CSS 占位画面**（见
`src/site.ts` 的槽位机制），放入文件后刷新即替换，无需改代码。

本目录内容不进 git（见同目录 `.gitignore`）——录屏是体积大户，各自本地保管。

> Hero 首屏已改为纯 CSS 三幕滚动叙事（设备电柜 → DIN 导轨母线 → 终端点亮），
> 不再需要录制 hero-dashboard.mp4。

## 待录制清单

| 文件名 | 用途（槽位） | 内容 | 要求 |
| --- | --- | --- | --- |
| `device-manager.png` | 主页「设备管理」展示块 | 设备管理设置页：连接 LED、组健康灯、点表实时值 | 2560 宽或 2x、暗色模式 |
| `process-page.png` | 主页「终端作业」展示块 | 故障或维护流程页（红/黄状态灯上镜） | 2560 宽或 2x、暗色模式 |
| `plugin-settings.png` | 插件页「离线安装」配图 | 应用内「插件」设置页（源设置 + 分类目录 + 组合安装预览） | 2560 宽或 2x、暗色模式 |

## 录制小贴士

- 统一暗色模式（设置键 `ui.theme` = dark），与官网基调一致。
- mock 驱动跑数即可出效果，无需真硬件。
- 组合包安装预览的录屏里不要出现本机真实路径。
