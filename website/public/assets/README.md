# 素材槽位说明

本目录存放官网的录制素材。**文件缺失时网站自动显示 CSS 占位画面**（见
`src/site.ts` 的槽位机制），放入文件后刷新即替换，无需改代码。

本目录内容不进 git（见同目录 `.gitignore`）——录屏是体积大户，各自本地保管。

> Hero 首屏已改为纯 CSS 三幕滚动叙事（设备电柜 → DIN 导轨母线 → 终端点亮），
> 不再需要录制 hero-dashboard.mp4。
