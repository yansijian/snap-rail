quick start

从下载到第一个点。

两步安装，一个测试。先确认“通不通、值是多少”，再决定要不要装场景、接更多设备。 全程离线可做；终端不需要访问 GitHub。

下载 Windows 客户端 按步骤走

downloads

先下这两个。

客户端 + 标准基座是第一次的最小组合。想看完整画面，再加一个产线看板场景包。

01 · 必装

Windows 客户端

Windows 10/11 x64

安装包，装好打开。未做商业代码签名，SmartScreen 可能提示“未知发布者”。

下载安装包
02 · 第一次必装

标准基座

standard-base · v1.1.0 · 约 450 KB

存储、设备底座、界面框架、设备管理页。拖进客户端，重启一次。

下载标准基座（.zip）
03 · 想看完整场景

产线看板场景包

production-board · v1.1.0 · 约 2.9 MB

在标准基座上加 ModbusTCP 采集与生产作业套件；装完按第 5 步建演示设备。

下载产线看板（.zip）

安装包未做商业代码签名；企业可自行签名。安装包与场景包都可以离线拷贝； feed 同源，客户端内“软件更新”走同一目录。

the first run

五步，跑通一个点。

前两步是安装；后三步是“建设备 → 测连接 → 建点”。每一步都可在车间离线完成。

01

装客户端

双击安装包。SmartScreen 提示时点“更多信息 → 仍要运行”。装完打开，先看到内核引导页。

首次启动
引导页 = 拖入 zip / 搜索插件源的入口
02

装标准基座

把 standard-base.zip 拖进引导页（或「插件」页），确认安装；装完重启客户端一次。

重启后
设置 → 设备管理 出现
03

新建设备，点“测试连接”

设置 → 设备管理 → 新建设备。选 ModbusTCP，填 IP、端口、单元号，点“测试连接”。

✓ 连接成功 · 12 ms
Unit 1 · FC3 @ 0 = 1843

失败也能先保存；按提示检查 IP、端口、防火墙、单元号。部分 PLC 只允许单连接，测试前先停用已有设备。

04

套模板，建点

保存设备后，点“从模板添加点位”。示例给 count / rate / running；地址按设备手册改。

line / count
FC3 @ 0 · int · 实时刷新

没有模板的驱动，也可以手动新建分组和点位；点位地址 = (设备, 组, 点) 三元组。

05

装场景包，看完整画面

把 production-board.zip 拖进「插件」页，确认安装，重启一次。按场景页的指引建一组演示设备即可看到班产看板。

重启后
生产作业页 · 班产统计 · 设备管理

组合包本身不签名，成员 zip 各自保留发布签名；安装预览逐成员显示验证结果。

where things live

东西都在哪。

现场排查时，先知道文件在哪、状态从哪看。

要找什么在哪说明
数据 / 配置%APPDATA%\snap-railSQLite 库、settings.json、presets、插件池；可用 SNAP_RAIL_HOME 改。
插件池%APPDATA%\snap-rail\plugins每个插件一个目录；安装/卸载走客户端，不建议手改。
场景预设%APPDATA%\snap-rail\presets组合包安装后写入 recipe-<id>.yml；删除即停用。
插件源设置 → 插件 → ⚙静态目录/Release 地址，可加多个；没网就留空，用 zip。
连接状态设置 → 设备管理设备在线灯、组健康灯、点位实时值；驱动未加载会显示“驱动未加载”。

troubleshooting

连不上时，先看这四行。

错误文案按“人话 + 下一步”写；先排除最常见的原因，再动设备。

现象先检查下一步
连接超时IP、端口、网线、防火墙；PLC 是否只允许一个连接先在 PC 上 ping 通，再用测试连接
连接被拒绝端口是否开在 PLC 上；ModbusTCP 默认 502，EtherNet/IP 默认 44818核对设备手册 / PLC 以太网设置
Modbus 异常码地址是否存在、功能码是否匹配、单元号是否正确按异常码查地址表；先用一个已知寄存器试
“驱动未加载”驱动插件是否安装/启用；设备页是否已重启插件页启用驱动，重启一次
还卡住？到 GitHub Issues 描述现场
