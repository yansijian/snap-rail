recipes

组合示例

组合（recipe）是随插件源分发的预设文档：基座组合一键装成可用终端，场景组合在基座之上叠加场景插件——看中哪个效果，装上就能复现。

reproduce

三步复现任意组合

1

下载并安装终端

从插件生态页下载 Windows 安装包。

2

填插件源，一键装组合

设置 → 插件市场，填入源地址（内网如 http://192.168.1.10/snap-rail/plugins/），在组合区点「一键安装」——缺失插件自动补齐，组合预设随之生效。

3

按指引看效果

场景组合卡片自带操作指引（如手动建一组演示设备），照做即可看到完整效果；「移除」即恢复干净。

publish your own

发布你自己的插件与组合

插件以源码形式提交到 snap-rail-market 社区仓，PR 合入即上架；组合是一份与 plugins.yml 同形状的 yml——在标准基座之上挑好插件、写清效果说明，提交即进入组合目录。插件按 requires 自动归入基座生态（命名不得占用 @snap-rail/*）。

阅读 architecture.md → 
# 组合 = 一份预设文档（recipes/<id>/recipe.yml）
version: 1.0.0
title: 我的产线看板
kind: scenario
plugins:
  - name: '@snap-rail/store-sqlite'
  - name: '@snap-rail/equipment'
  - name: '@myScope/my-driver'
  # …与 plugins.yml 完全同形
