combos

组合套件

组合是一份随组合包分发的预设文档（recipe.yml）：基座组合一次装成可用终端， 场景组合在基座之上叠加场景插件。每个组合包就是一个 zip——联网 PC 下载，拷进内网，拖入终端即批量安装。

reproduce

离线三步复现任意组合

1

联网 PC 下载

下载终端安装包与组合包（.zip）。组合包已带齐全部成员插件，现场无需再找依赖。

2

拷进内网终端

安装终端后，把组合包拖进「插件」页：客户端按内容识别组合形式，逐个安装成员（同名保留本机更新版本），最后原子写入组合预设。

3

按指引看效果

场景组合卡片自带操作指引（如手动建一组演示设备），照做即可看到完整效果。组合的启用方式是 <home>/presets/recipe-<id>.yml，删除预设文件即恢复干净。

publish your own

自己发布插件与组合

没有集中市场上架流程：插件住在你自己的 GitHub 仓库，用你自己的 Ed25519 密钥签名，发布成自仓滚动 Release（feed 标签）。在仓库打上 snap-rail-plugin topic，用户就能在 GitHub 发现你，并把你的 Release 地址加为插件源。组合包也是你自己的 zip：根目录 recipe.yml + plugins/*.zip，成员保留各自签名。

浏览社区插件 → 插件开发指南 → 
# 组合包（<id>.zip）的唯一清单
id: my-line-board
version: 1.0.0
title: 我的产线看板
kind: scenario
plugins:
  - name: '@snap-rail/store-sqlite'
  - name: '@snap-rail/equipment'
  - name: '@my-scope/my-driver'
  # …与 plugins.yml 完全同形

# zip 内容：recipe.yml + plugins/*.zip
# 成员 = 逐个签名的一方/三方插件 zip
