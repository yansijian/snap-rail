scene packs

装一个场景包，
终端就变成那个工位。

场景包是普通 zip：一组插件 + 一份预设。联网 PC 下载，拷进内网，拖进客户端， 重启一次就位。成员各自带发布签名；组合包本身只是容器。

下载客户端 看安装步骤

available now

现在能装的场景。

场景包可以叠加安装。每个 zip 都带齐成员插件，现场不需要再找依赖。

offline install

三步，进内网。

现场不一定有网，甚至不应该有网。安装路径按“离线优先”设计。

STEP 0101

联网 PC 下载

下载客户端安装包；需要驱动或场景插件时，从插件页取对应 zip。

snap-rail-setup.exe
driver-modbus.zip
STEP 0202

拷进内网

U 盘、堡垒机、文件摆渡都行。终端不需要访问 GitHub 或任何插件服务器。

车间网络
→ 只读本地 zip
STEP 0303

拖入，重启

把插件 zip 拖进「插件」页；重启一次，驱动就绪，可以开始建设备。

插件页 → 拖入 zip
重启 · 生效

your own scene

你的场景，也可以是一个场景包。

设备协议、工艺画面、报表格式不在现成场景里？用 plugin SDK 做自己的驱动、界面或套件， 打包成 zip，用你自己的密钥签名，发布到你自己的插件源。

DRIVER

接一种新设备

照抄 driver-modbus：上交 schema + createConnection，设备/组/点仍然住在底座表里。

插件开发指南
UI / SUITE

做一个专用画面

用内置语义 UI 的共享原语做页面，把场景逻辑和界面收进一个套件包，单活切换。

PACK

打成一个场景包

根目录 recipe.yml + plugins/*.zip；成员各自签名，客户端按内容识别、批量安装、写预设。
