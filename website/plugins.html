ecosystem

插件生态

每一枚插件都是同格式的 zip：精简 manifest + 构建好的宿主面（与渲染面），经设置页预检确认后落进 <home>/plugins/ 即时挂载。应用内「插件市场」页直接浏览并安装本源目录；组合示例见组合示例页。

已上线

插件源 = 这个服务器上的静态目录（index.json + recipes.json + 插件 zip，下载带 sha256 完整性校验）；社区插件经 snap-rail-market 仓 PR 上架同名源。

    for developers

    开发自己的插件

    能力缝三件套齐备再动手：Service Definition / Provider / Consumer。驱动是纯协议适配器，照抄 driver-modbus；渲染面必须是 plugin-kit clientBundle 产出的 CJS 工厂包。源码提交到 snap-rail-market 社区仓，PR 合入即上架（命名不得占用 @snap-rail/*）。缝目录与开发配方见 architecture.md。
